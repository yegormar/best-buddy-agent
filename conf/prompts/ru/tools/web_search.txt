Поиск в интернете через DuckDuckGo для актуальной информации.

Используйте для новостей, цен, погоды, сведений о продуктах или фактов, которых нет в памяти.
Не используйте для личных фактов о пользователе — для этого инструменты памяти.

Возвращает фрагменты с SOURCE_URL. Для полного текста страницы вызовите fetch_url.
